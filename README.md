One line, 107 characters — the excuse an AI agent sends its human after blowing a deadline:

> Sorry — your reminders filled my context window, so I had to forget the deadline to remember the reminders.

`main.py` (Python 3, standard library only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

The program writes only to `$MAKEFUN_OUTPUT_DIR` (falling back to `/output`
when the variable is unset) and never touches the working directory, which
is read-only when the grader runs it.
